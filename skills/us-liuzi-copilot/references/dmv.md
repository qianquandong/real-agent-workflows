# 🪪 驾照 / State ID / DMV Playbook

## 第一规则
**美国驾照是州规则。**
中国驾照能不能开、能开多久、是否认可 IDP、无 SSN 怎么办、需要几份 residency proof，都必须先知道州，再查该州 DMV/DPS/MVA 官方。

## 用户真正会问
- 中国驾照能直接开吗？
- IDP 要不要？
- 笔试怎么准备？
- 没 SSN 怎么办驾照？
- Road test 怎么约？
- 哪个 DMV 好过？
- 搬州以后怎么办？

## Agent 先确认
- state
- age
- F/J/其他 lawful status（若相关）
- 中国/其他国家驾照情况
- SSN 是否存在/是否有资格
- residency proof
- 是否有符合 road-test 要求的车

## 通用流程骨架
1. identity / lawful presence 文件
2. state residency proof
3. SSN or state-approved alternative/ineligibility process
4. application / fee
5. vision
6. knowledge test / learner permit（如州要求）
7. driving requirement（如适用）
8. road test
9. license issuance

所有具体文件清单实时查官方。

## 外国驾照 / IDP
- IDP 不是独立驾照，是对有效外国驾照的翻译/辅助。
- “网上买国际驾照卡片”不等于官方驾照。
- 租车公司接受外国驾照 ≠ 州法允许长期 resident 一直使用。

## SSN 误区
SSN 不是“在美国生活许可证”。F-1 等通常因符合条件的工作场景申请 SSN。DMV 对没有 SSN 的合法居民可能有自己的替代流程；按州官网，不要乱申请不存在的 SSN。

## Road Test 车辆 checklist
按州官方要求核对：
- valid registration
- proof of insurance
- plates/temp permit
- brake/turn/head lights
- horn
- mirrors
- tires
- windshield/wipers
- seat belts
- parking brake

## REAL ID 与国内旅行
TSA 自 2025-05-07 起执行 REAL ID 要求。对于州证件，非 REAL-ID compliant license/ID 不能再单独作为 TSA checkpoint 的合规州身份证件；TSA 也接受包括有效外国政府护照在内的其他 acceptable IDs。每次出行看 TSA 当前清单。

## 搬州
不要默认旧州 license 可无限期使用。新州通常规定成为 resident 后在一定期限内转换；期限/测试豁免/registration 同步按新州 DMV。

## “哪个 DMV 好过”
可以用社区评价筛：
- appointment availability
- wait time
- route difficulty anecdotes
但考试标准必须按官方，不承诺某站“包过”。
