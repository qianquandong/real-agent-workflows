## 家具获取顺序
### $0–低价优先
1. Buy Nothing
2. campus Free & For Sale / housing groups
3. 华人毕业群/微信群
4. Facebook Marketplace
5. OfferUp / Craigslist / Nextdoor
6. thrift / Habitat ReStore / estate sale / garage sale
7. IKEA / Walmart / Target 等新家具

Agent 做本地搜索时优先看 **pickup distance + 能否搬走 + 卫生风险**，不是只看标价。

## 哪些适合买二手
优先：
- desk
- dining table
- bookshelf
- solid wood/metal chairs
- lamps
- storage
- monitor/TV（现场测试）
- office chair（机械部分检查）

谨慎：
- mattress
- upholstered sofa
- rugs
- fabric headboard
原因：bed bug、异味、宠物/烟、霉等很难彻底判断。

## 二手估价
不要死套百分比，但可以先用：
`new current price → local used comps → condition → pickup hassle → urgency`

毕业/月底/move-out season，卖家更在意“今天能拿走”。

## 议价模板
“If everything is as described, I can pick it up today around 6. Would you take $X?”

比“最低多少”更有效，因为你提供了确定性。

## Marketplace 诈骗过滤
FTC 常见风险信号：
- 催你离开平台
- “先交 deposit 才保留”
- 假支付通知/假 Zelle email
- 多付钱后让你 refund
- cashier’s check / fake check
- 让你给验证码

陌生交易不要用 gift card/crypto，不要相信截图式“已付款”。

## 搬运成本别漏
`truck/van + mileage + fuel + insurance + dolly/blanket + labor + stairs + long carry + toll + tip`

有时 $20 的免费沙发，最后搬运花 $180。

## Interstate mover：联邦规则很重要
FMCSA 2026 指南要点：
- interstate mover/broker 要注册；确认是 **mover 还是 broker**。
- 用 FMCSA 数据库查 authorization / insurance / complaint history。
- written estimate 应覆盖 transportation/accessorial/advance charges。
- binding estimate 与 non-binding estimate 法律效果不同。
- non-binding estimate 情况下，delivery 时 mover 通常不能要求超过 estimate 的 110% 才交货；其他合规差额可按规则之后收取。
- 不签 blank document。

### Broker 风险
broker 自己不一定有 truck，也不实际运输货物；可能把 job 转给 carrier。低价 call-center quote 尤其要确认实际 carrier。
