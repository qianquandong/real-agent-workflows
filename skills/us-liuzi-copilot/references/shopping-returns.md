# 购物 / 退货 / 保修 Playbook

## 买大件前
查：retailer return window、restocking fee、opened-item policy、delivery/assembly fee、manufacturer warranty、信用卡 extended warranty（若有）。

## 美国退货不是统一法律“无条件 7 天”
多数普通商品退货政策由商家决定，少数州/品类有特殊规则。不要把中国电商习惯带过来。

## 收货
贵重电子产品开箱录像；保留 serial number 和包装直到确认无问题。

## Price match / price adjustment
商家政策经常变，购买后降价可实时查是否能做 adjustment。

## Chargeback
先和商家解决；若商品未收到/欺诈等符合信用卡争议条件，再按发卡行流程。不要把 chargeback 当“后悔退货”。

## 学生省钱
买电脑/软件先查学校 bookstore、教育优惠、校园 license，不急着原价买。
