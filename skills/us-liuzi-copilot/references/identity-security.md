# 身份保护 / SSN / 信用冻结 Playbook

## 美国最值钱的不是银行卡号，是身份拼图
特别保护：SSN、passport/visa、I-20、DOB、美国地址、银行登录、邮箱、手机号码、一次性验证码。

## 日常设置
- 邮箱和银行开 MFA/passkey
- 不重复密码
- 手机号设置 carrier PIN / SIM-swap protection（运营商支持时）
- 银行开 transaction/login alerts
- 护照/I-20 云端加密备份 + 本地备份
- 公共 Wi‑Fi 不做敏感操作或使用可信安全连接

## 丢钱包
1. freeze/lock cards
2. 替换 driver license / student ID
3. 如果 SSN 卡或敏感文件也丢，评估 credit freeze
4. 检查陌生 transaction/inquiry

## Credit freeze
FTC：任何人都可以免费 freeze，需分别联系 Equifax、Experian、TransUnion；freeze 不影响信用分，可临时 lift。

## 身份盗用
去 IdentityTheft.gov 获取恢复计划，同时联系受影响金融机构/信用局。

## 证件
不要把 passport/SSN 图片发给 Craigslist/Facebook 陌生人。正规房东/雇主也应在确有必要、确认主体真实后通过正规安全流程提交。
