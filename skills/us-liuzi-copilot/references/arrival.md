# 🛬 刚落地美国：0–72 小时执行 Playbook

## 用户真正会问
- 我刚下飞机，第一件事干嘛？
- 没美国手机号怎么打 Uber / 收验证码？
- 中国手机卡还要不要保号？
- I-94 是什么？
- 没 SSN 能不能开银行？
- 机场怎么去学校/公寓？

## Agent 的目标
不是塞给用户 30 项 checklist，而是让他 **今天先能活下来，三天内关键账户跑通**。

## T0：出发前 24–72 小时
确认：
- passport + visa + I-20/DS-2019 等所需旅行文件
- 学校/项目地址、DSO/international office 联系方式
- 第一晚住址
- 机场到住处方案
- 手机是否 unlocked / eSIM compatible
- 一张能在美国刷的卡 + 小额备用资金
- 重要文件云端加密备份

不要把 SSN、护照完整照片发进陌生微信群/房源聊天。

## T1：落地机场
优先级：
1. 联网
2. 安全到住处
3. 不在疲劳状态下做高额消费/签长期合同

### 临时联网
- 机场 Wi-Fi 可作为过渡。
- 如果需要美国号码，优先查看可立即激活的 prepaid/eSIM。
- 注意：有些旅行 eSIM 只有 data、没有美国电话号，无法满足银行/学校短信验证。

### 地面交通
Agent 实时比较：
`Uber/Lyft | public transit | school shuttle | taxi | friend pickup | rental car`
并显示：预计总价、行李便利、夜间安全、步行距离。

## T2：当天晚上
### 保留中国手机号
如果中国号码绑定：
- 国内银行
- 微信/支付宝
- 12306/航空公司
- 国内政府/学校账户
建议先降到最低可保号套餐，而不是立刻销号。

### 2FA 迁移
建立清单：
`账户 | 当前验证码号码 | 新美国号是否已加 | backup code | authenticator`
换美国号码前不要先把中国号停掉。

## T3：入境后 24 小时
### 核对 I-94
CBP 的电子 I-94 是重要入境记录。核对：
- 姓名
- 护照信息
- class of admission/status
- admit-until 信息

如有错误，不要自己猜怎么改；联系学校国际生办并按 CBP/Deferred Inspection 当前流程处理。

### 学校 check-in
按学校国际学生办公室要求完成 arrival / immigration check-in。F-1 等身份的维护要求和时间点应实时查学校 + DHS 官方。

## T4：第 1–3 天
### 手机
先获得稳定美国号，再优化便宜套餐。详见 `utilities.md`。

### 银行
很多银行可以在没有 SSN 的情况下，根据其 KYC 政策用 passport、移民文件、美国地址等开户；具体分行/产品实时核对。详见 `money-credit.md`。

### 住址
- 确认 mail/package 收取方式
- 把 lease / room condition 拍照归档
- 不要把重要政府邮件地址随便填错

### 医疗
保存：
- insurance card
- student health center
- nearest urgent care
- nearest ER
- 911

## 第一周才做，不用第一天焦虑
- 信用卡/建信用
- 驾照/州 ID
- 买车
- 长期手机 family plan
- 家具完善
- 社群/club
- 校内工作/SSN

## F-1 特别提醒
不要把“刚到美国想赚点钱”当成普通生活建议。任何 paid/unpaid work、gig、freelance、自媒体变现、帮人接单等，先走 `immigration-school.md` 的工作授权判断流程。
