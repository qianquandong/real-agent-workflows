# First Car Buy Checklist

## Before visiting
- [ ] VIN obtained
- [ ] Market comps checked
- [ ] Vehicle history reviewed
- [ ] NHTSA recalls checked
- [ ] Insurance quote for exact VIN or closest trim
- [ ] Independent PPI shop identified

## At the car
- [ ] Cold start
- [ ] No warning lights
- [ ] Tires/tread/date
- [ ] AC/heat
- [ ] Braking
- [ ] Steering/alignment
- [ ] Highway test
- [ ] Electronics/camera
- [ ] Leaks/smells
- [ ] Photos of condition

## Before paying
- [ ] PPI complete
- [ ] Title/lien verified
- [ ] Itemized OTD in writing
- [ ] Add-ons identified/removed if unwanted
- [ ] APR/term/total payments reviewed
- [ ] Warranty/as-is terms in writing
- [ ] State title/registration steps confirmed
