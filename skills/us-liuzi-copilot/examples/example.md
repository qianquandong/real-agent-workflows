# 真实使用示例

## 例 1：刚落地
**用户**：我下周到 Dallas 读书，第一次来美国，什么都没弄。

**Agent 行为**：
1. 最多补问学校、第一晚住处、有无接机。
2. 立即给 0–72h 顺序：联网 → 住处 → I-94/check-in → 美国号 → 银行 → insurance/health。
3. 不在第一天强推买车、办多张卡或买全套家具。

## 例 2：无信用租房
**用户**：UTD，预算 $1,400，没有 SSN，也没有 credit score，9 月住。

**Agent 行为**：
1. 实时搜 inventory，预算按 all-in 而不是 base rent。
2. 高峰通勤圈。
3. 对每家 property 查 no-credit/no-SSN applicant alternative。
4. 自动生成 no-credit application packet。
5. 最近 reviews 扫 pest/towing/package/maintenance。
6. 给 2 个最值得 tour 的，而不是丢 20 个链接。

## 例 3：回长沙
**用户**：12/1–12/15 从 DFW 去长沙，最多转一次，两件托运行李。

**Agent 行为**：
- DFW→CSX 直搜。
- 日期网格。
- DFW→中国/亚洲 gateway + 国内段。
- protected connection 优先。
- 算 bag、overnight、地面交通和 domestic leg。
- 给 cheapest / balanced / easiest，并可做价格监控。

## 例 4：第一辆车
**用户**：预算 $10k，学校离家 20 分钟，想买 Corolla/Civic。

**Agent 行为**：
- 先把 tax/title/insurance 留出预算，避免 $10k 全花在 sticker price。
- 搜本地 VIN。
- vehicle history + recall。
- exact/close VIN insurance quote。
- PPI。
- dealer 要 itemized OTD。
- 输出 3 台以内可真正去看的车。

## 例 5：附近吃饭
**用户**：两个人，附近吃点正宗川菜，不要太贵。

**Agent 行为**：
- 用当前位置实时搜。
- 看 open now / 人均 / 近期 reviews / 中国胃反馈 / 停车。
- 1 家首选 + 2–4 备选。
- 3 家以上直接地图。

## 例 6：找朋友
**用户**：我来三个月了还是没朋友，美国人上课聊完就没下文。

**Agent 行为**：
- 不给“自信点”鸡汤。
- 找本周 recurring club/sport/volunteer。
- 只排 1–3 个。
- 给一个具体邀约句子，把 “sometime” 变成日期+活动。
- 让用户连续去 6 周再判断圈子合不合适。

## 例 7：F-1 自媒体赚钱
**用户**：我是 F-1，我做小红书接广告可以吗？

**Agent 行为**：
- 不直接 yes/no。
- 拆清：是否已接单、付款形式、谁付款、内容是主动服务还是其他收入、当前 CPT/OPT/STEM 状态。
- 查当日 DHS/USCIS/SEVP 规则。
- 明确税务 1099 与 immigration work authorization 不是一回事。
- 给 DSO 问题模板。

## 例 8：海运
**用户**：从中国寄 5 箱衣服零食药过来，哪家靠谱？

**Agent 行为**：
- 先分品类：普通个人物品 / 食品农产品 / 药品 / battery。
- 先查 CBP/FDA/USDA/承运商禁限运。
- 再拿统一 L×W×H/重量向多家报价。
- 比实际/体积重、清关、住宅、保险、storage、赔付和 door-to-door 总价。

## 例 9：医生账单
**用户**：看了一次 urgent care，保险后又寄来 $600，啥意思？

**Agent 行为**：
- 让用户区分 EOB vs provider bill。
- 对 date/service/allowed/paid/patient responsibility。
- 查 network/denial reason。
- 要 itemized bill。
- 适用时看 No Surprises / estimate / assistance。

## 例 10：毕业回国
**用户**：两个月后回国，车、房、银行卡、手机号、东西怎么办？

**Agent 行为**：
- 走 `leaving-us.md`。
- T-60/T-30/T-14/last-week 时间线。
- 车 sale/title、lease notice/deposit、2FA/号码、tax documents、shipping、银行 KYC/地址逐项处理。
